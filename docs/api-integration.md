# Implementation interfaces

Current source locations follow `docs/project-structure.md`: database/transactions in `backend/src/config/database.ts`, auth in `backend/src/middleware/auth.middleware.ts`, HTTP helpers in `backend/src/utils/http.ts`, AppError in `backend/src/errors/app-error.ts`, and HTTP registrations/handlers in `backend/src/routes` / `backend/src/controllers`. Older short filenames below describe the same interfaces before the directory reorganization.

All routes `/api/v1`, JSON success `{data,meta?}`. Error `{error:{code,message,fields?,requestId}}`. Dates ISO, IDs UUID, version integer. Admin cookie and `X-CSRF-Token` on writes, token from GET `/admin/auth/me`. Login Origin must match APP_ORIGIN.

Shared `packages/contracts/src/index.ts` defines Content, guestSchema (camelCase), rsvpSchema, wishSchema, assetIds and publicationErrors. Content follows original DOCX section 11, locations contain UTC startAt/endAt, venueName/address/lat/lng/entranceNote. Theme palette cream/sage/rose, font serif/sans. All eight section types with data matching DOCX.

Guest `/guest/invitation` data: `{content,media,guest:{displayName,fullName,salutation},personalMessage,rsvp,wish,canRsvp,canCreateOrEditWish,canWithdrawWish,eventId}`. media is object keyed asset ID, values `{id,url,alt,type,width,height,srcSet?}`. rsvp/wish nullable, existing wish includes deletedAt and version. Body expectedVersion 0 when absent. `Authorization: Bearer <token>` on all guest routes. Opened is POST. RSVP/wish PUT needs `Idempotency-Key` header UUID. Wish visibility PATCH only consentPublic false + expectedVersion; DELETE body expectedVersion. Wall GET `{items,nextCursor}`, only safe public fields. Calendar fetch with Authorization then blob.

Admin current event GET `/admin/events/current`: `{id,version,draftRevisionId,publishedRevisionId,publishedAt,rsvpEnabled,wishesEnabled,wallEnabled,draft:{contentJson,...},published:{contentJson,...}|null}`. Draft PATCH `/admin/events/:id/draft`: body `{content:Content}`, If-Match header Event version; response same event DTO. Publish/unpublish POST `{expectedVersion}`; controls PATCH expectedVersion and booleans. Preview GET returns InvitationView plus preview true, guestId query optional. Dashboard `{total,attending,declined,unanswered,pendingWishes,opened}`.

Admin guests GET `/admin/events/:id/guests`: query q,group,status (ATTENDING/DECLINED/UNANSWERED),archived (true/false/all),page,pageSize,sort; data `{items,total,page,pageSize}`. Each guest safe admin record plus invitation `{id,version,revokedAt,openedAt,rsvp,wish}` (no hash/ciphertext). POST guestSchema camelCase response guest+invitation. PATCH `/admin/guests/:id`: guestSchema + expectedVersion + expectedInvitationVersion; body includes all current form fields. Archive/restore POST `{expectedVersion}`. Link GET `/admin/invitations/:id/link`: `{url,message}`. Revoke/rotate POST `{expectedVersion}`. Admin RSVP PUT `{status,note,expectedVersion,reason}`.

Admin wishes GET `/admin/events/:id/wishes`: query status optional NONE/PENDING/APPROVED/HIDDEN/DELETED, page/pageSize; `{items,total,page,pageSize}` records include invitation.guest. Moderation PATCH `/admin/wishes/:id/moderation`: `{action:'APPROVE'|'HIDE',expectedVersion}`. Pin PATCH `{isPinned,expectedVersion}`.

Imports module to export `importRouter`; media module `mediaRouter`. Routers receive mount API root, use `requireAdmin` on admin endpoints. Helpers in http.ts: `AppError(status,code,message,fields?)`, `ok(res,data,status=200)`, `ownedEvent(req,eventId,tx?)` returns owned event or throws; `audit(tx,req,action,eventId,entityType,entityId,metadata?)`; `pagination(req)` -> `{page,pageSize,skip}`. auth.ts exports requireAdmin and requireGuest. Request `req.admin={id,email,csrfToken,sessionId}`, `req.invitation` Prisma include guest,event,rsvp,wish; `req.requestId`. `config` camelCase properties, `prisma` global. crypto.ts createInvitationToken(id) returns token,tokenHash,tokenCiphertext,keyVersion; decryptInvitationToken(id,ciphertext,keyVersion); hashToken(string).

Imports endpoints: GET `/admin/imports/template` xlsx; POST `/admin/events/:id/imports/inspect` multipart file -> `{sheets:[{name,headers:string[]}]}`; POST preview multipart file,sheet,mapping(JSON canonical snake_case => original header). GET batch -> batch DTO `{id,status,summary,rows,errors,expiresAt}`. POST commit `{}` Idempotency-Key required -> `{created,updated,unchanged}`. GET batch/report returns xlsx of errors. Exports GET `/admin/events/:id/exports/:kind`, kind links/responses, filters as guests incl history. Dates/filter metadata in file.

Media endpoints: GET `/admin/events/:id/media` -> `{items}`; POST same multipart file,alt; PATCH `/admin/media/:id` `{alt}`; DELETE `/admin/media/:id`. Export async `mediaUrls(content:Content,admin:boolean):Promise<Record<string,MediaView>>` and `preparePublishedMedia(eventId:string,content:Content):Promise<void>`. Private local media signed URL bounded lifetime with HttpOnly admin session check. Public serving only public copies.

Database Prisma schema is stable in backend/prisma/schema.prisma. Revision references FK constraints added by migration. Guest.module and imports create Invitation ID first, encrypt token with ID AAD; `prisma.invitation.create` data omits plaintext token. Import rows store versions, invitation fields separately. Transactions use serializable or row lock plus conditional versions and retry serialization failures. `withTransaction(fn)` in db.ts retries P2034 up to 3, and `idempotent(req,scope,actorHash,body,fn)` in http.ts authenticates before entry and transactionally runs fn(tx), records/replays data, requires header, hashes canonical request body. Guest route handlers recheck activity/publication within same transaction.

Tests: Vitest fileParallelism false; `backend/tests/helpers.ts` exports setupTestData() returning admin,event,content,guest,invitation,token,csrf,cookie; resetTestDatabase() deletes children then parents. Integration uses TEST_DATABASE_URL if set, otherwise DATABASE_URL only when database name ends `_test`. Root prepares tests database invitations_test and `.env.test`; never reset dev DB. Tests requests set Origin http://localhost:5173.
